FINTOLO LANGGRAPH FLOW
======================

Graph Name: Fintolo Financial Intelligence Pipeline
Engine: LangGraph StateGraph
Entry Point: load_data_trigger
Exit Point: END

Visual Builder Style Flow
-------------------------
1) load_data_trigger
   - Trigger node starts run from uploaded or configured datasets
   - Inputs:
     - transactions_data.csv
     - users_data.csv
     - cards_data.csv

2) fintolo_ai_agent_hub
   - Central orchestrator node (like the AI Agent node in your reference image)
   - Calls analysis tools as branches and merges outputs

3) tool_branches attached to agent hub
   - enrich_data_tool
     - Joins transactions + cards + users on client_id and card_id
   - spending_kpi_tool
     - total_spend, total_transactions, avg_transaction, category and monthly aggregates
   - fraud_signal_tool
     - error-based flags, dark-web card exposure, z-score outlier checks
   - financial_health_tool
     - debt-to-income, credit utilization, credit score profiling
   - segmentation_tool
     - Healthy, At-Risk, Stressed + age-band split

4) email_report_node
   - Consolidates tool outputs
   - Generates executive summary and report payload

5) fintolo_delivery_node
   - Sends output to UI panels and chatbot reply channel
   - Optional artifact/export handoff (markdown, pdf, pptx)

6) finalize
   - Marks run completed and returns terminal state


Primary Edge Sequence
---------------------
load_data_trigger
   -> fintolo_ai_agent_hub
   -> email_report_node
   -> fintolo_delivery_node
   -> finalize
   -> END

Tool Branch Edges (fan-out / fan-in)
------------------------------------
fintolo_ai_agent_hub
   -> enrich_data_tool
   -> spending_kpi_tool
   -> fraud_signal_tool
   -> financial_health_tool
   -> segmentation_tool

All tools
   -> email_report_node
